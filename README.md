# JavaScript Memory Game

A responsive card-matching memory game built with vanilla JavaScript.

## Features

- Twenty shuffled cards with ten matching pairs
- Move, match, and time tracking
- Locked board while unmatched cards reset
- Complete restart and play-again flows
- Keyboard-accessible card controls
- Responsive layout and reduced-motion support

## Built With

- Semantic HTML5
- Modern CSS
- Vanilla JavaScript
- DOM state and event handling
- Fisher–Yates shuffle
